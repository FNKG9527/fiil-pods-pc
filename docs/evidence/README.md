## 日志格式约定

### 会话日志（`fiil_log_*.txt`）

```
15:49:24.613  TX  setUnlock（连接握手）        00 27 01 00 04 FF 02 02 34
15:49:24.660  RX  RESP cid=39 cmd=255 len=1    00 27 02 00 03 FF 01 FF
```

左侧为本地时间戳，`TX` 为主机发往耳机，`RX` 为耳机回包。

### 探测日志（`table_*` / `set_*` / `unverified_*`）

```
[TX] setUnlock                00 27 01 00 04 FF 02 02 34
     [RX] 00 27 02 00 03 FF 01 FF            RESP cid=39 cmd=255 len=1
```

`[TX]` 后为命令名，右侧为十六进制字节；`[RX]` 行为回包字节与解析结果。

### 十六进制约定

字节之间以单个空格分隔，全部大写。`xx` 出现时表示该位置的 `seq` 字段（实际日志中为具体值）。

## 复现说明

这些日志对应的是一台具体设备的一次调试会话，**不是可重复运行的测试套件**。要复现：

1. 准备一台 Mate 机型（earType 45–53）的 FIIL 耳机
2. 按 `PROTOCOL_PC.md` §4 的顺序握手
3. 逐条发送 `unverified_cmdid_20261025_014438.txt` 中的命令

不同固件版本的返回值可能不同。**如果你的结果与本目录的日志不一致，那是新数据，不是错误**——请按 [CONTRIBUTING.md](../../CONTRIBUTING.md) 提交，并附上你的固件版本。
